# Room schemas

Room exports the database schema of every version here (`exportSchema = true`).
The files are generated by the build (`./gradlew :app:assembleDebug`) and MUST be
committed. Whenever an entity changes: bump the database version, add a
`Migration`, commit the new schema file and add a migration test. Never use
destructive migrations: the on-device database is the primary copy of the
training data until it has been synced.
